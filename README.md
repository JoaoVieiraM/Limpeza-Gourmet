# Limpeza Gourmet - Pós-Obra & Facilities de Alto Padrão

Bem-vindo ao repositório do **Limpeza Gourmet**, uma landing page premium desenvolvida para apresentar serviços de limpeza pós-obra e gestão de facilities de alto padrão. Este projeto foca em transmitir excelência, sofisticação e a qualidade técnica dos serviços oferecidos.

## 📋 Sobre o Projeto

A **Limpeza Gourmet** oferece soluções especializadas para ambientes de luxo, utilizando uma metodologia internacional (Bermuda & UK Standard). O site serve como um ponto de contato digital para clientes exigentes que buscam:
- Limpeza Pós-Obra Premium
- Facilities Executive para residências e escritórios corporativos
- Revitalização de superfícies nobres (mármores, metais, etc.)

A interface foi projetada para refletir esses valores através de um design elegante, animações suaves e uma experiência de usuário fluida.

## ✨ Funcionalidades

- **Hero Section Imersiva**: Apresentação impactante com imagem de fundo e chamada de ação clara.
- **Diferenciais Técnicos**: Destaque para a metodologia internacional e equipe qualificada.
- **Catálogo de Serviços**: Detalhamento das áreas de atuação (Pós-Obra, Facilities, Revitalização).
- **Portfólio Interativo**: Carrossel de imagens "Antes e Depois" demonstrando a eficácia dos serviços.
- **Depoimentos**: Seção de prova social com feedback de clientes e parceiros.
- **Formulário de Contato Direto**: Integração para contato via WhatsApp e formulário de solicitação de orçamento.
- **Design Responsivo**: Totalmente adaptado para dispositivos móveis, tablets e desktops.
- **Animações de Scroll**: Transições suaves e efeitos visuais ao navegar.

## 🚀 Tecnologias Utilizadas

Este projeto foi construído com ferramentas modernas para garantir performance e manutenibilidade:

- **[React 19](https://react.dev/)**: Biblioteca JavaScript para construção da interface.
- **[Vite](https://vitejs.dev/)**: Ferramenta de build rápida e servidor de desenvolvimento.
- **[TypeScript](https://www.typescriptlang.org/)**: Superset do JavaScript para maior segurança e produtividade no código.
- **[Tailwind CSS](https://tailwindcss.com/)**: Framework CSS utility-first para estilização ágil e responsiva.
- **[Font Awesome](https://fontawesome.com/)**: Ícones vetoriais modernos.

## 🛠️ Instalação e Execução

Para rodar o projeto localmente, siga os passos abaixo:

### Pré-requisitos
- Node.js instalado (versão recomendada: 18+).

### Passos

1. **Clone o repositório** (ou baixe os arquivos):
   ```bash
   git clone <URL_DO_SEU_REPOSITORIO>
   cd Limpeza-Gourmet
   ```

2. **Instale as dependências**:
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento**:
   ```bash
   npm run dev
   ```
   O projeto estará disponível em `http://localhost:5173` (ou outra porta indicada no terminal).

4. **Para construir para produção**:
   ```bash
   npm run build
   ```

## 📂 Estrutura do Projeto

O código principal reside em `App.tsx`, que orquestra as seções da landing page como componentes:
- `Header`: Navegação e menu mobile.
- `Hero`: Seção principal de destaque.
- `Diferenciais`: Ícones e textos de valor.
- `Servicos`: Grid de serviços oferecidos.
- `Portfolio`: Carrossel de imagens de projetos.
- `AboutUs`: Seção sobre a metodologia e garantia.
- `Testimonials`: Avaliações de clientes.
- `ContactForm`: Formulário de contato e links sociais.
- `Footer`: Rodapé com links rápidos e copyright.
